# 🚀 Flight Trajectory Simulator

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/irahimov646/Flight_trajectory_simulator/blob/main/flight_Trajectory_Simulator.ipynb)

Математическое моделирование и симуляция 3D-траектории полета воздушного судна с учетом аэродинамических сил, параметров атмосферы и численных методов интегрирования.

## 📌 Основные возможности и физическая модель
* **Учет основных сил:** Тяга (Thrust), Лобовое сопротивление (Drag), Подъемная сила (Lift) и Вес (Weight).
* **3D-динамика:** Моделирование углов ориентации (Крен/Roll, Тангаж/Pitch, Рыскание/Yaw) и пространственных маневров.
* **Внешняя среда:** Учет изменения плотности воздуха и температуры с высотой, а также векторных сдвигов ветра.
* **Численные методы:** Сравнение точности интегрирования дифференциальных уравнений (Метод Эйлера vs Рунге-Кутты RK4 vs Метод Верле).

## 🎯 Сферы применения
* **Оптимизация маршрутов:** Снижение коммерческих расходов за счет расчета оптимального профиля полета при разном ветре.
* **Проектирование систем управления:** Наземное тестирование алгоритмов автопилота перед установкой на реальные БПЛА.
* **Авиатренажеры:** Математическое ядро для комплексных тренажеров подготовки пилотов.
